


# Critical User Tasks-Smart Onboarding (Prioritised)


## Task 1-Use the AI assistant to find the correct onboarding document

**Pain point:** Information is scattered across multiple systems, and users
do not know which version is correct (H2- all 6 interview participants
independently raised this).

**Success measure:** User finds the correct document and its source link
within 2 minutes.

---

## Task 2- Find the correct person to contact for a specific question

**Pain point:** Users do not know who to ask, or worry about asking the
wrong person (H3- raised by P02 and P06).

**Success measure:** User finds the correct contact within 30 seconds,
using the support suggestion feature (routes to HR, IT, or manager based
on question type).

---

## Task 3 — Complete Day 1 tasks and understand what's next

**Pain point:** New starters are overwhelmed by unprioritised access to
many systems, and often don't know their next priority once initial
tasks are done (H1-raised by P02, P03, P05, P06).

**Success measure:** User identifies their top priority task within 1
minute, and correctly states what's done and what's next using the
progress tracker and smart reminders.

---

## Deprioritised (not part of the core 2–3 for prototyping/testing)

**Task 4- Recognise role-specific content (H4)**- kept in the design
and IA, but not selected as one of the core tested tasks for this round,
since Tasks 1–3 already cover the group's strongest, most universally
supported evidence (H1, H2, H3). Role-specific content can be tested in
a later round if time allows.
