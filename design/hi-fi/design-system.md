# Mini Design System — Smart Onboarding

For Shubham to use when converting wireframes into high-fidelity screens.

## Typography
- Headings: Sans-serif, 18–22px, medium weight
- Body text: 14–16px, regular weight
- Labels/metadata (e.g. "Updated 2 days ago"): 11–12px, muted colour

## Colours
| Role | Colour | Use |
|---|---|---|
| Primary accent | Teal `#0F6E56` | Primary buttons, active nav item, progress bar fill |
| AI / smart feature tag | Purple `#7F77DD` | "AI recommended," "Smart reminder" badges |
| Success / complete | Green `#3B6D11` | Completed task checkmarks |
| Warning / overdue | Coral `#D85A30` | Overdue task labels, smart reminder banners |
| Neutral surfaces | Gray `#F1EFE8` (light), `#FFFFFF` (cards) | Backgrounds, card fills |
| Borders | Light gray `#D3D1C7` | Card borders, dividers |

## Components
- **Buttons:** rounded corners (8px radius), primary = teal fill + white text, secondary = white fill + border
- **Cards:** white background, 12px radius, 1px border, consistent padding (16–20px)
- **Progress bar:** teal fill, light gray track, rounded ends
- **Badges/tags:** small rounded pill, coloured background matching role above (e.g. purple pill for "AI recommended," coral pill for "Overdue")
- **Navigation (sidebar):** persistent left sidebar, active item has light gray background highlight

## Icons
Simple line icons (checkmarks, document, person, chat bubble) — consistent stroke weight across the whole app.
